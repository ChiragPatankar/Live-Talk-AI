# LiveTalk AI: Talking Head Video Generator
## Comprehensive Implementation Guide

## 1. PROJECT OVERVIEW

LiveTalk AI generates realistic talking head videos from a single image and text script. The system processes these inputs to create videos with synchronized lip movements, natural eye blinking, and appropriate facial expressions.

### Core Functionality
- **Input**: One portrait image (.jpg/.png) + text script (.txt)
- **Output**: Video of the person speaking the script naturally
- **Features**: Lip-syncing, eye blinking, facial expressions

### Use Cases
- Virtual presenters for educational content
- Marketing videos with minimal production costs
- Accessible content creation for non-video professionals
- Converting blog posts to video content
- Multilingual presentations from a single source image

## 2. SYSTEM ARCHITECTURE

### Component Breakdown
1. **Input Processing Module**
   - Image preprocessing (face detection, alignment)
   - Text processing (parsing, emotion tagging if applicable)

2. **Audio Generation Module**
   - Text-to-Speech conversion
   - Optional voice customization

3. **Video Animation Module**
   - Face animation based on audio
   - Lip synchronization
   - Natural facial movements

4. **Output Processing Module**
   - Video rendering and compression
   - Format conversion
   - Quality enhancement

### Data Flow
```
Input Image → Face Detection → Face Alignment → Face Model
                                                     ↓
Input Text → TTS Engine → Audio File → SadTalker → Video Animation
                                                     ↓
                                           Post-processing → Final Video
```

### Step 2: Image Preprocessing Module
```python
# image_processor.py
import cv2
import dlib
from mtcnn import MTCNN

class ImageProcessor:
    def __init__(self):
        self.face_detector = MTCNN()
        self.landmark_predictor = dlib.shape_predictor("shape_predictor_68_face_landmarks.dat")

    def process_image(self, image_path):
        """
        Process input image for optimal face animation
        - Detect face
        - Align face if needed
        - Crop to optimal size
        - Return processed image
        """
        image = cv2.imread(image_path)

        # Detect faces
        faces = self.face_detector.detect_faces(cv2.cvtColor(image, cv2.COLOR_BGR2RGB))
        if not faces:
            raise Exception("No face detected in the image")

        # Get largest face
        largest_face = max(faces, key=lambda x: x['box'][2] * x['box'][3])
        box = largest_face['box']

        # Add margin for better animation
        margin = int(max(box[2], box[3]) * 0.3)
        x1 = max(0, box[0] - margin)
        y1 = max(0, box[1] - margin)
        x2 = min(image.shape[1], box[0] + box[2] + margin)
        y2 = min(image.shape[0], box[1] + box[3] + margin)

        # Crop image
        face_image = image[y1:y2, x1:x2]

        # Save processed image
        processed_path = "processed_" + image_path.split("/")[-1]
        cv2.imwrite(processed_path, face_image)

        return processed_path
```

### Step 3: Text-to-Speech Module
```python
# tts_generator.py
import os
from bark import SAMPLE_RATE, generate_audio, preload_models

class TTSGenerator:
    def __init__(self):
        # Preload Bark models
        preload_models()

    def generate_audio(self, text, output_path="output.wav", voice_preset="v2/en_speaker_6"):
        """
        Generate speech audio from text
        - Convert text to audio using Bark
        - Save to output path
        - Return path to audio file
        """
        # Generate audio
        audio_array = generate_audio(text, history_prompt=voice_preset)

        # Save audio
        write_wav(output_path, SAMPLE_RATE, audio_array)

        return output_path

    def generate_from_file(self, text_file, output_path="output.wav", voice_preset="v2/en_speaker_6"):
        """
        Generate speech from text file
        """
        with open(text_file, 'r', encoding='utf-8') as f:
            text = f.read()

        return self.generate_audio(text, output_path, voice_preset)

# Helper function for saving wav files
def write_wav(path, sample_rate, audio_array):
    from scipy.io.wavfile import write as write_wav
    # Normalize audio
    audio_array = audio_array / np.max(np.abs(audio_array))
    # Convert to int16
    audio_array = (audio_array * 32767).astype(np.int16)
    # Write to file
    write_wav(path, sample_rate, audio_array)
```

### Step 4: Video Animation Module (Using SadTalker)
```python
# video_animator.py
import os
import sys
import subprocess

class VideoAnimator:
    def __init__(self, sadtalker_path):
        """
        Initialize with path to SadTalker repository
        """
        self.sadtalker_path = sadtalker_path

    def generate_video(self, source_image, audio_file, output_dir="results",
                       enhance=True, still_mode=False, expression_scale=1.0):
        """
        Generate talking head video using SadTalker
        - source_image: Path to the input image
        - audio_file: Path to the audio file
        - output_dir: Directory to save the result
        - enhance: Whether to enhance the face
        - still_mode: If True, less head motion
        - expression_scale: Control level of facial expression (0.0-2.0)
        """
        # Create output directory if not exists
        os.makedirs(output_dir, exist_ok=True)

        # Prepare SadTalker command
        cmd = [
            "python", f"{self.sadtalker_path}/inference.py",
            "--driven_audio", audio_file,
            "--source_image", source_image,
            "--result_dir", output_dir,
            "--expression_scale", str(expression_scale)
        ]

        # Add optional parameters
        if enhance:
            cmd.append("--enhance")
        if still_mode:
            cmd.append("--still")

        # Run SadTalker
        try:
            subprocess.run(cmd, check=True)
            output_video = os.path.join(output_dir,
                                       os.path.basename(source_image).split('.')[0] +
                                       '_' + os.path.basename(audio_file).split('.')[0] + '.mp4')
            return output_video
        except subprocess.CalledProcessError as e:
            print(f"Error running SadTalker: {e}")
            return None
```

### Step 5: Main Integration Script
```python
# livetalk_ai.py
import os
import argparse
from image_processor import ImageProcessor
from tts_generator import TTSGenerator
from video_animator import VideoAnimator

def main():
    parser = argparse.ArgumentParser(description="LiveTalk AI - Generate talking head videos")
    parser.add_argument("--image", required=True, help="Path to the input image")
    parser.add_argument("--text", required=True, help="Path to the text script")
    parser.add_argument("--output", default="output", help="Output directory")
    parser.add_argument("--voice", default="v2/en_speaker_6", help="Voice preset for Bark TTS")
    parser.add_argument("--expression", type=float, default=1.0, help="Expression scale (0.0-2.0)")
    parser.add_argument("--still", action="store_true", help="Reduce head motion")
    parser.add_argument("--enhance", action="store_true", help="Enhance face quality")
    args = parser.parse_args()

    # Create output directory
    os.makedirs(args.output, exist_ok=True)

    print("LiveTalk AI - Processing started")

    # Step 1: Process the input image
    print("Processing input image...")
    image_processor = ImageProcessor()
    processed_image = image_processor.process_image(args.image)

    # Step 2: Generate audio from text
    print("Generating speech from text...")
    tts_generator = TTSGenerator()
    audio_file = tts_generator.generate_from_file(
        args.text,
        output_path=os.path.join(args.output, "speech.wav"),
        voice_preset=args.voice
    )

    # Step 3: Generate talking head video
    print("Generating talking head video...")
    video_animator = VideoAnimator("./SadTalker")
    output_video = video_animator.generate_video(
        processed_image,
        audio_file,
        output_dir=args.output,
        enhance=args.enhance,
        still_mode=args.still,
        expression_scale=args.expression
    )

    if output_video and os.path.exists(output_video):
        print(f"Video generation successful! Output saved to: {output_video}")
    else:
        print("Video generation failed.")

if __name__ == "__main__":
    main()
```

## 6. TROUBLESHOOTING & OPTIMIZATION

### Common Issues and Solutions

**1. Face Detection Failures**
- **Problem**: No face detected in the input image
- **Solutions**:
  - Use a clear frontal portrait with good lighting
  - Try increasing image resolution
  - Adjust face detection confidence threshold
  - Try alternative face detection models

**2. CUDA/GPU Issues**
- **Problem**: CUDA out of memory or GPU errors
- **Solutions**:
  - Reduce batch size or model complexity
  - Close other GPU-intensive applications
  - Update NVIDIA drivers
  - Try using CPU mode for smaller projects

**3. Audio-Visual Sync Problems**
- **Problem**: Misalignment between speech and lip movements
- **Solutions**:
  - Check audio sample rate consistency
  - Apply small offset to sync timing
  - Re-encode video with consistent frame rate
  - Use a different TTS model

**4. Animation Quality Issues**
- **Problem**: Unnatural movement or artifacts
- **Solutions**:
  - Adjust expression scale parameters
  - Try "still mode" for less movement
  - Use enhance option in SadTalker
  - Experiment with different preprocessing methods

### Performance Optimization

**1. Processing Speed**
- Use GPU acceleration whenever possible
- Preload models during initialization
- Process audio and image in parallel
- Consider batch processing for multiple videos

**2. Video Quality**
- Optimize final video encoding parameters:
  ```python
  # Example ffmpeg command for better quality
  ffmpeg -i input.mp4 -c:v libx264 -preset slow -crf 22 -c:a aac -b:a 128k output.mp4
  ```
- Adjust resolution based on use case
- Consider post-processing with video enhancement tools

**3. Memory Usage**
- Clear cached tensors when processing multiple videos
- Use streaming techniques for larger inputs
- Implement resource cleanup in try/finally blocks
